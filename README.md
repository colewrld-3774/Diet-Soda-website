# Diet Soda 3D Website

An interactive, 3D landing page for a fictional "Diet Soda" beverage built with pure HTML, CSS, JavaScript, GSAP, and Google's `<model-viewer>`.

## Features
- **3D Model Viewer**: Interactive 3D soda can that tilts with cursor movement.
- **Dynamic Flavor Switcher**: Seamlessly toggle between "Diet Classic" and "Zero Lime" with custom 720° spin animations, texture changes, and background morphs.
- **Physics & Parallax**: Floating berry & leaf models with cursor repulsion and floating animations.
- **Zero Build Setup**: Pure single-file architecture deployed effortlessly on GitHub Pages.
