# Pure Soda Uganda 🇺🇬 — 330ml Canned Sodas E-Commerce

An interactive, 3D e-commerce landing page tailored for the **Ugandan beverage market**, featuring only **330ml canned editions** of Uganda's favorite sodas: **Coca-Cola Original**, **Sprite Lime**, **Stoney Tangawizi**, **Fanta Orange**, **Mountain Dew**, and **Pepsi Max**.

## Features

- **100% Canned Sodas**: Sourced in 330ml aluminum cans at authentic Ugandan market prices (`UGX 3,000` / single can, `UGX 17,500` / 6-pack, `UGX 34,000` / 12-pack, `UGX 66,000` / 24-can crate).
- **Interactive 3D Can & Physics**: Real-time cursor tilting, GSAP 720° spin animations on flavor switch, floating berry & leaf repulsion physics, and endless bubble effects.
- **Uganda Mobile Money Checkout**:
  - **MTN MoMoPay**: Merchant Code (`884422`), MoMo number (`0770 123 456`), and USSD guide (`*165*3#`).
  - **Airtel Money Pay**: Merchant Code (`993311`), Airtel number (`0700 987 654`), and USSD guide (`*185*9#`).
  - **One-Click Copy** for merchant codes and phone numbers.
  - **Scan QR Code** option for the MoMo / Airtel Money app.
  - **Direct WhatsApp & Call Admin Confirmation** with pre-filled order receipt details.
- **Fully Working Glassmorphism Tabs**:
  - **Home**: Resets modal overlays and focuses on the 3D hero.
  - **Ingredients**: Authentic nutritional and natural extract facts for Ugandan canned sodas.
  - **Taste**: Sensory profiles for Sprite Lime, Stoney ginger kick, Fanta orange, and Coca-Cola.
  - **Eco (Kampala Green Initiative)**: Highlights the 100% infinitely recyclable aluminum can circular economy in Uganda.
  - **Reviews**: Verified customer testimonials from Kampala (Kololo, Bugolobi, Nakasero).
  - **Contact Us**: Kampala Industrial Area distribution hub, hotlines, and fast message form.
